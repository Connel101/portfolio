# Virtual CV

This repository contains my virtual CV. It is a single-page website with my work experience, projects,
skills, education and GitHub profile.

## What is included

- A short About Me section
- My work experience in a CV timeline
- Project pages for VisionBench and Caddyfile Builder
- Technical skills grouped by area
- Education and certification
- A GitHub contact link
- A printable version of the CV

## Tech used

- HTML
- Tailwind CSS through the CDN
- Custom CSS for the layout, responsive design, animations and print view
- Vanilla JavaScript for the menu, active navigation and interactive system map

The site does not need a build step. It can be opened from `index.html` or
hosted directly with GitHub Pages.
